# Sunset Cover Studio

Sunset Cover Studio is an offline browser app that turns a photo and a caption into GTA 6-style cover art. Load a photo from your machine, crop and position it across a multi-panel poster, write a bold caption, and export the finished cover as a PNG. Every panel gets the Vice City treatment: a neon-sunset colour grade, strong lettering, and the poster look of a game cover — all rendered locally in the browser, with nothing uploaded anywhere.

## Run it

```sh
npx serve app
# or
python3 -m http.server -d app
```

Then open `index.html` in desktop Chrome.
